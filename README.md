# Advanced-Windows-Device-Manager
AdvancedDeviceManager | Open Source, free to edit and sell, (pls give credit)

Advanced Windows Device Manager (Pre-Alpha)
This is basically a more detailed version of the default Windows Device Manager. Instead of just showing a list of devices and whether they’re working or not, it tries to give a fuller breakdown of what’s actually going on with your hardware and drivers.
It includes things like more detailed device info, extra driver data, error logs, and some basic tracking for things like disconnects or weird behavior over time. The idea is to make it easier to spot problems or just understand your system a bit better without digging through a bunch of different menus and tools.
Right now it’s in pre-alpha, so it’s still pretty rough. Some stuff might not work properly, some info might be off, and parts of it are still unfinished. It’s mainly just a test build to see how everything comes together.
If you try it and something seems broken, confusing, or just useless, that kind of feedback actually helps a lot.
